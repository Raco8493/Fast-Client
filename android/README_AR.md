# Hostphone 1.2 - واجهة وإعدادات أداء Android حقيقية

تم حذف اعتماد التطبيق الخارجي على Termux نهائيًا من هذه النسخة. APK بوضع Portrait بالكامل، بواجهة حمراء وشريط تنقل دائري أسفل الشاشة.

- قائمة الإنشاء تضم Java وBedrock وGeyser فقط.
- حقل إصدار Java وحقل إصدار Bedrock ديناميكي حسب الاختيار؛ Geyser يستخدم الاثنين.
- عرض RAM الحقيقية: الإجمالي والمتاح والمستخدم وذاكرة عملية Hostphone نفسها (PSS)، وعدد أنوية المعالج، واستهلاك عملية Hostphone من قدرة CPU الإجمالية، وحالة الحرارة حيث يدعمها النظام.
- حفظ اختيار حد RAM (25%-85%) وعدد أنوية JVM المستهدفة، لكن **لا يتم فرضها على أي سيرفر في هذه النسخة**.
- تم حذف أذونات Termux تمامًا من AndroidManifest واستخدام Android APIs الأصلية فقط.

## الحالة الفعلية والمحدودية

**التطبيق ليس سيرفر Minecraft قابلًا للعب بعد**: محرك Java ARM64 أو PowerNukkitX غير مضمن، ولا توجد خدمة تشغيل للسيرفر. صفحة السيرفر تعلن ذلك صراحة بدلاً من ادعاء Online. كان الإصدار السابق يستضيف عبر Termux؛ بعد إزالته لا يجوز الادعاء أن الوظيفة مستمرة بدون بديل حقيقي.

دمج سيرفر فعلي من غير تطبيق Termux خارجي يحتاج بيئة Java أصلية على ARM64 داخل APK مع تفاصيل التراخيص والتشغيل على Android والإصدارات، أو استخدام قاعدة تطبيق مفتوح المصدر تدعم ذلك فعليًا مثل Minexa (GPL-3.0) مع احترام الترخيص. ملف Bedrock الرسمي لا يعمل على ARM64؛ يمكن استخدام محرك بديل مثل PowerNukkitX. Geyser ليس سيرفرًا منفصلًا، بل جسر لعملاء Bedrock نحو سيرفر Java.

بيانات الجهاز محدثة على الشاشة؛ استعمال 90% من المعالج ليس إعدادًا يمكن لتطبيق عادي ضمانه. يجب الاحتفاظ بقدر من RAM للنظام لتجنب إغلاق السيرفر تحت الضغط.
